Access, migration & usability

From native services
to an integrated stack.

Remote access repair

TUN passthrough restored Tailscale operation

The unprivileged media container lacked the networking device Tailscale needed. Device passthrough and a container stop/start enabled the daemon. Account authorization completed the connection.

Verification · Tailscale connectivity, Jellyfin health response, and HTTP 200 from the web interface.

Docker migration

Media applications moved into Compose

Jellyfin, Radarr, Sonarr, Prowlarr, and qBittorrent moved from native services into Docker. Dedicated application data and a shared media filesystem supported the new layout.

Recovery provision · The pre-migration Proxmox snapshot was retained.

Dashboard improvements

Homarr became the mobile entry point

Quick links and download progress lead the phone layout. Playback, calendar, requests, storage, backup status, Proxmox resources, and Docker state provide operational context.

Verification · Eight integrations passed connection checks. Desktop and iPhone-sized browser checks passed.

Shared media filesystem

Downloads and library imports share a filesystem, supporting hardlinks where configured. Application data uses dedicated directories.

Private administration

Tailscale provides service access from authorized clients. qBittorrent shares Gluetun's network namespace.

Live operational cards

The storage card reads filesystem capacity through Radarr every minute. The backup card reads Proxmox job and archive information every five minutes.
